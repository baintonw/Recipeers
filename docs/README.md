## Code and checkpoints

From Part 3 onward, the reference app is built incrementally in `../app/` (a single Next.js
project). At each Part's checkpoint the repo is committed and tagged — e.g. `part-03-complete` —
so you can `git checkout part-05-complete` to see the app exactly as it should look at that stage.
